# ELA 300-Level Production Engineering Reports

Open `index.html` in a browser. It is an offline, responsive report companion for Experiments 301–308 in the supplied ELA manual.

## Included

- One easy-to-navigate HTML site with an overview, experiment switcher, sidebar contents and a print-current-experiment action.
- Detailed, professional explanations of the theory, apparatus, procedures, precautions, discussions and conclusions for each experiment.
- Manual questions, learning outcomes and optional/special questions.
- 24 selected local technical figures under `assets/diagrams/`.

## Data integrity

The supplied material did not include completed experimental readings. The site intentionally contains **no fabricated values, tables or graphs**. The data and graph sections explain what would be recorded, so actual laboratory readings can be added if required by the lecturer.

The original repository also contains the supplied page photographs. Blurred page photographs were not embedded as diagrams; only readable circuit, machine-connection, phasor and signal figures selected from the referenced manual set are used in the report.
